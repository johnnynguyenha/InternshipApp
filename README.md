# InternshipApp
Created a Windows app that features login/signup, user management, capture packets on the network, chatbox communication using SerialRS232 and TCP/IP , and script communication to a robot arm.
Database stores encrypted information about the user, their role, and permissions.
Includes business practices such as proper logging, SOLID principles, and separation of UI, logic, and data.
Technologies: C#, .NET, WinForms, SQL, SQLite, Entity Framework
